# Nationelle Intelligence

Static editorial publication for Nationelle Intelligence.

The site is intentionally built with production HTML and CSS only. Run `npm test` before deployment to validate metadata, links, assets, structured data, and crawl files.

## Deployment

- Preview: `vercel deploy . -y`
- Production: promote only after review and explicit production approval.
- Custom domain: configure separately after ownership and DNS approval are confirmed.

## Rollback

Promote the last verified immutable Vercel deployment. Do not change DNS as part of a content rollback.
